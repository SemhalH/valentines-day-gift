# 💝 Valentine's Day Gift Website

A cute and interactive **Valentine's Day Gift Website** created with **HTML, CSS, and JavaScript**.
The project is designed as a digital Valentine's surprise containing placeholders for personal letters, secret messages, music, GIFs, images, notes, and interactive elements.

## 💕 Features

* 💌 **Love Letter** — A personal letter displayed as part of the surprise.
* 🔐 **Secret Code** — A secret/password-protected message for the recipient to discover.
* 🎵 **Music** — Background or romantic music to create a special atmosphere.
* 🎞️ **GIFs** — Animated GIFs to make the website more fun and expressive.
* 🖼️ **Images** — Personal or romantic images displayed throughout the website.
* 📝 **Notes** — Sweet personal notes and messages.
* ✨ **Interactive Elements** — JavaScript-powered interactions and surprises.
* 💻 **Responsive Design** — Designed to work on different screen sizes.

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/SemhalH/valentines-day-gift.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd valentines-day-gift
```

### 3. Run the website

Open `index.html` directly in your browser, or use **VS Code Live Server** for a better development experience.
